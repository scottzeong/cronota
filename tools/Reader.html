설정·백업

목소리가 없거나 어색할 때

Reader는 기기에 설치된 음성 합성(TTS) 목소리를 그대로 써요. 목소리를 바꾸거나 더 받으려면:

  1. 갤럭시: 설정 → 일반 → 글자 읽어주기(TTS) → 기본 엔진에서 삼성 TTS 또는 Google 음성 엔진을 고르고, 언어 데이터를 내려받아요.
  2. 윈도우: 설정 → 시간 및 언어 → 음성 → 음성 추가에서 한국어를 더해요. Edge 브라우저는 자연스러운 온라인 목소리를 더 많이 보여 줘요.
  3. 맥·아이패드: 손쉬운 사용 → 콘텐츠 말하기 → 음성에서 ‘유나’ 같은 한국어 목소리를 내려받아요.

목소리를 새로 받았다면 이 페이지를 새로 고쳐 주세요.

문장 나누기

긴 문장은 쉼표나 띄어쓰기에서 잘라 읽어요. 읽다가 혼자 멈추는 기기라면 더 짧게 해 보세요.

백업

보관함의 모든 자료와 설정, 발음 사전을 JSON 파일 하나로 받거나, 받은 파일을 다시 불러와요. 불러오면 지금 보관함에 더해져요.

Reader는 이렇게 써요글을 넣으면 소리 내어 읽어 줘요

흐름

  • ‘넣기’에서 글을 붙여 넣거나 파일을 고르면 보관함에 저장되고 읽기 화면이 열려요.
  • 재생 버튼을 누르면 문장 하나씩 읽고, 읽는 문장에 색이 칠해져요. 기기가 지원하면 지금 읽는 단어도 표시돼요.
  • 아무 문장이나 누르면 거기서부터 읽어요. 멈춘 자리는 저장되어 다음에 이어 읽어요.
  • 책갈피, 목차, 찾기로 원하는 곳으로 바로 갈 수 있어요.
  • 속도·높낮이·목소리를 바꾸면 지금 읽는 문장부터 바로 바뀌어요.

약속

  • 소리 파일을 만들지 않아요. 기기의 음성 합성으로 그 자리에서 읽어요.
  • 글은 이 브라우저에만 저장돼요. PDF를 처음 열 때만 PDF 도구를 인터넷에서 한 번 받아요.
  • 화면이 꺼지거나 다른 앱으로 가면 기기에 따라 읽기가 멈출 수 있어요. ‘화면 켜 두기’를 켜 두세요.
