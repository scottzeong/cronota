Colorer 사용법

선택한 색 (오른쪽 패널)

  • 어느 탭에서든 색을 누르면 오른쪽 패널의 "선택한 색"이 돼요.
  • HEX, RGB, HSL, HSV, HWB, CMYK, Lab, LCH, OKLCH, 안드로이드 값을 한 번에 보여 주고, 누르면 복사돼요.
  • 입력칸에는 #244D3A, rgb(36,77,58), hsl(…), oklch(…), tomato 같은 CSS 색 이름을 넣을 수 있어요.
  • 스포이트 버튼은 PC 크롬·엣지에서 화면 아무 곳의 색이나 찍어요. 태블릿에서는 이미지 추출 탭에서 사진을 눌러 찍으세요.

팔레트

  • Space 또는 "새로 만들기"로 새 조합을 만들어요. 자물쇠로 잠근 색은 그대로 남아요.
  • 조화 규칙은 OKLCH(사람 눈에 고르게 보이는 색 공간)에서 계산해요.
  • "선택한 색 기준"을 켜면 선택한 색을 첫 색으로 두고 규칙을 적용해요.
  • CSS 변수, SCSS, Tailwind, JSON, GIMP(GPL), Adobe(ASE), PNG, SVG로 내보낼 수 있어요.

대비 검사

  • WCAG 2.1 기준: 일반 글자 AA 4.5:1, AAA 7:1, 큰 글자(24px 또는 굵은 18.7px 이상) AA 3:1, AAA 4.5:1, 아이콘·테두리 같은 UI 3:1.
  • APCA Lc 값도 함께 보여 줘요. 본문은 |Lc| 75 이상, 큰 제목은 60 이상을 권장해요.
